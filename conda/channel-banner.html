The AI-assisted Isabelle stack (Isa-Mini/AoA, the Isabelle MCP server and the semantic database) is published as the isabelle-ai package.

If you are installing it for the first time, create a new conda environment that contains it:
  conda create -n <YOUR_ENVIRONMENT_NAME> -c https://conda.qiyuan.me -c conda-forge isabelle-ai

If you already have such an environment and want to update isabelle-ai in it, activate the environment and run the update:
  conda activate <YOUR_ENVIRONMENT_NAME>
  conda update -c https://conda.qiyuan.me -c conda-forge isabelle-ai
